Tecnología de Vanguardia

Arquitectura & Stack Tecnológico

Construido sobre una infraestructura moderna, reactiva y de alto rendimiento.

⚛️
Next.js 16 + React 19
App Router para Server-Side Rendering rápido, rutas protegidas y Tailwind CSS 4 para diseño responsivo.
🛡️
Supabase + PostgreSQL
Autenticación SSR robusta, triggers automáticos para perfiles y restricciones de integridad en base de datos.
🚀
Vercel + HTML5 QR
Despliegue global continuo CI/CD con renderizado en el Edge y lectura directa de hardware de cámara.

Integridad de Datos

Reglas de negocio y anti-fraude

Protecciones tanto a nivel de cliente como en la capa profunda de base de datos.

🔒
Asistencia Única por Día
Restricción única por base de datos: ningún estudiante puede registrarse dos veces en la misma sesión.
⏳
Expiración Estricta del Token
Tokens UUID efímeros que quedan automáticamente invalidados al agotarse el tiempo configurado.
🌐
Auditoría con IP y Timestamp
Cada registro almacena la dirección IP y la hora exacta (scanned_at) para verificación posterior.
Flujo Operativo

¿Cómo funciona en una clase real?

Un proceso que toma menos de un minuto para todo el salón de clases.

PASO 01
El Docente Inicia
Selecciona la materia, define minutos activos y proyecta el código QR en pantalla.
→
PASO 02
El Alumno Escanea
Ingresa a la app desde su móvil, apunta la cámara al proyector y valida su identidad.
→
PASO 03
Consolidación Inmediata
La asistencia queda registrada en la nube, visible en el listado del profesor y lista para exportar.
